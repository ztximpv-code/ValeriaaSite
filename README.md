# Валерія Гуровська — адаптивний двомовний сайт

Готовий статичний сайт. Українська — головна сторінка `/`, російська — `/ru/`. Мобільні телефони, планшети, ноутбуки, десктопи, широкі монітори та 4K екрани підтримуються CSS breakpoint-ами і fluid-типографікою. Навігація з клавіатури, reduced-motion, safe-area для мобільних. Підтримка пульта Smart TV не тестувалась.

## Публікація через Cloudflare Pages

Для тимчасового публічного перегляду: у Cloudflare Dashboard відкрийте Workers & Pages → Create → Pages → Direct Upload та завантажте файли з кореня цього проєкту (щоб `index.html` лежав у корені). Після публікації Cloudflare надасть адресу `*.pages.dev`.

Для подальшого оновлення: створіть GitHub репозиторій, завантажте файли сайту, а в Cloudflare Pages оберіть Connect to Git → GitHub та вкажіть репозиторій. Збірка не потрібна; output directory — корінь репозиторію.

Перед запуском перевірте план хостингу, актуальну адресу сайту та метадані SEO: у HTML і sitemap.xml зараз вказано `https://YOUR-DOMAIN.cz`. Налаштуйте robots.txt і надішліть актуальну sitemap до Google Search Console після запуску.
